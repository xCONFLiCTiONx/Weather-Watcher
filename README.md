# Weather Watcher

Weather Watcher is a modern, reliable Android weather application designed to keep you updated on the latest weather conditions, forecasts, and emergency alerts across the United States. Built entirely with Kotlin, Jetpack Compose, and modern Android architecture practices.

<br clear="left"/>

---

## 🚀 Features

- **Accurate Forecasts:** Hourly and daily forecast data retrieved from the National Weather Service (NWS).
- **Severe Weather Alerts:** Background tracking and real-time push notifications for critical weather hazards and infrastructure alerts.
- **Dynamic Animations:** Immerse yourself in the weather conditions with rich, smooth Lottie weather animations.
- **Location Flexibility:** Choose between precise GPS-based location tracking or manual city searches.
- **Personalized Experience:** Full support for both Imperial/Metric units and custom application themes.

## 🛠️ Tech Stack & Architecture

- **UI Toolkit:** Jetpack Compose for declarative, responsive UI design.
- **Asynchronous Flow:** Kotlin Coroutines & Flow for efficient state management and background operations.
- **Networking:** Retrofit combined with Kotlinx Serialization for fast, type-safe API communication.
- **Background Sync:** WorkManager for reliable, power-efficient background weather updates and notification checking.
- **Local Storage:** Encrypted SharedPreferences/Preferences for local data persistence.

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/weather-watcher.git
   ```
2. Place your `logo.png` in the root folder of the project if you wish to display your custom branding in this README.
3. Open the project in Android Studio.
4. Build and run the app on an Android device or emulator (Android 8.0+ / API 26+).
